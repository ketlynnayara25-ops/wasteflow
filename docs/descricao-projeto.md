# WasteFlow — Lixeira Industrial Inteligente

## Sobre o projeto

O WasteFlow é uma proposta de lixeira industrial inteligente voltada para ambientes corporativos.

O projeto busca auxiliar na separação correta dos resíduos por meio de tecnologias como inteligência artificial, câmera e sensores.

## Funcionalidades propostas

- Identificação de materiais por câmera e inteligência artificial.
- Monitoramento do nível de preenchimento da lixeira.
- Exibição de orientações em uma tela.
- Alertas por pulseira inteligente.
- Separação dos resíduos por categorias.

## Objetivo

Incentivar o descarte correto, facilitar a coleta seletiva e contribuir para uma gestão mais eficiente dos resíduos.

## Status
